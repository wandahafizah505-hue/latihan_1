Kelas: XI RPL 3

Jurusan: Rekayasa Perangkat Lunak

Saya adalah siswi SMK jurusan Rekayasa Perangkat Lunak yang tertarik mempelajari teknologi dan pengembangan website. Dalam proses belajar, saya mempelajari HTML untuk membuat struktur halaman, CSS untuk mengatur tampilan, dan JavaScript untuk menambahkan fitur interaktif. Saya juga belajar menggunakan Bootstrap agar website lebih rapi dan responsif, serta mulai mengenal PHP dan MySQL untuk pengembangan website dan pengelolaan database. Saya ingin terus meningkatkan kemampuan melalui latihan dan berbagai proyek sederhana agar dapat membuat website yang menarik, bermanfaat, dan nyaman digunakan.
